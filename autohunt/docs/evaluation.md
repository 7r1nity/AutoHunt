## 运行

在 `agent` 目录运行：

```powershell
.\.venv\Scripts\python.exe -m evaluation.run
.\.venv\Scripts\python.exe -m evaluation.run --browser-fixtures --kinds browser
.\.venv\Scripts\python.exe -m evaluation.run --kinds semantics slots gold_plan execution delivery_contract
```

前者使用临时 SQLite、生产解析/校验/DST/执行代码与合成执行器；不读取个人数据库、不启动服务、不使用当前浏览器。后者启动新的无头 Chromium，所有请求在浏览器中拦截/中止，只验证生产 DOM 适配器。没有启动模拟站的后端，也没有向真实网站发送请求。

获得向已配置 DeepSeek 发送合成请求/JD 的明确同意后才运行：

```powershell
.\.venv\Scripts\python.exe -m evaluation.run --models-consented --models-only --model-call-limit 120
```

模型模式只读模型配置/加密凭据，不读取简历、聊天或申请记录，不调用招聘工具。120 是本进程物理 API 请求上限，规划修正也计入，无传输自动重试。多次运行需要人工累计预算；本次经用户同意总计不超过120次。可用 `--kinds model_expression model_dialogue` 选择层，`--repetitions 2` 重复同一批表达；重复尝试不是新独立样本。

失败返回非零退出码，保留所有失败，不用 xfail/放宽期望掩盖。无同意的模型层、未选择的浏览器层显示 skipped，不算通过。静态验证入口 `scripts/verify.ps1` 与行为评估分开。
