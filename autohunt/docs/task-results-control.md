# 停止与执行中查询的结果交付

2026-11-26。

## 行为

- 聊天发送 `stop`、`Stop for now`、`stop now`、`停止任务`、`停止并返回当前结果`，或点击停止按钮，都会停止当前会话的工作并返回已保存结果。`stop all` / `停止所有任务` 使用全部会话范围。
- `Status?`、`How's it going?`、`How many jobs?`、`当前结果`、`查看当前申请进度` 等完整查询走只读通道。前台仍在等待规划、执行或模型响应时也可发送，不取消原任务，不改其条件、计划、授权或简历绑定。
- 这些是明确控制指令的正向快捷路径。引用、否定、询问停止功能和混合业务指令不会仅因包含 stop/停止而取消任务；其他表达仍保留正常模型理解路径。
- 正常搜索、每日任务和投递共用结果快照。搜索还没完成、每日任务还没有 `selected` 清单时，也可展示当前已核对并持久化的岗位。

## 唯一结果投影

`runtime/task_results.py` 提供 `read_task_snapshot(runs, jobs, session_id, run_ids=None)` 和 `render_task_snapshot(snapshot)`。它只读取任务绑定、搜索成员、阶段记录和投递回执，不启动浏览器、模型、搜索或投递。

快照包含当前阶段、读取时间、本轮发现/核对/符合条件数量、已沟通、等待 HR、已核实投递、待沟通、失败、待核验，以及岗位清单和可点击来源。岗位按 ID 去重，不用全局看板的前 10/100 条代替当前任务；显示岗位 ID，不重新定义用户原来的“第几个”简表。

默认读取当前会话的活动工作，空闲时读取最近实际工作及其绑定子任务。控制查询记录不会变成新的业务任务，也不会替换原需求。显式停止范围保留原运行 ID；查询按会话隔离。全部会话停止的回复写回发起操作的会话。

只有 `submitted` 标记或确认回执才计作投递成功；仅入队、执行完成和阶段声称已发送不算成功。发送开始后无确认回执仍标为待核验，不为统计重发。今日数量仅采用有确认时间的会话绑定回执，缺失时间时说明不可可靠统计。完整历史导出入口会明确包含其他轮次。

## 控制与消息链路

```text
用户文字 / 停止按钮
  → 类型明确的停止或只读结果请求
  → 停止：持久化撤销并有界清理；查询：直接读已存证据
  → 同一个任务结果快照与渲染器
  → 持久化聊天消息 + HTTP / SSE
  → 前端按 message_id 合并展示
```

- `POST /api/v1/runs/control/results`：`conversation_id`、`message`、可选 `request_id`。返回 `message`、`snapshot`、`snapshot_id`、`message_id`、`run_id`。不等待会话执行锁、执行槽、规划或记忆压缩；客户端请求 ID 可去重。
- `POST /api/v1/runs/control/stop` 与对应 GET 轮询：保留 `status/message`，增加 `result_message`、`snapshot`、`snapshot_id`、`message_id`。超过即时等待时先返回 `stopping` 与部分结果；停止失败明确保留未确认状态，不宣称全部停止。
- 前端通过既有 Next 同源代理调用，服务端鉴权不变。轮询、HTTP、事件流和刷新恢复使用同一持久消息身份，避免重复打印结果。
- 重复停止只在同一发起会话、工作版本及最新证据都未变化时复用结果；新一轮已完成任务或迟到回执不会被旧缓存覆盖。
- 待完成的 stop/progress 控制记录恢复时不会作为普通任务交给模型；停止结果和业务任务终态仍分别保存。

## 验收方式

在 `autohunt/agent` 中运行：

```powershell
python -m unittest evaluation.task_results_contract evaluation.task_control_contract -q
python -m evaluation.task_results_browser --mode both
```

页面验收需要本地前端已启动。浏览器中的所有业务接口都被截获：辅助场景用合成响应，完整链路场景连接隔离 ASGI 的生产路由、真实临时 SQLite 和受控执行器；不进入生产应用 lifespan，不读取用户材料，不操作现有队列，不调用外部模型。

验收同时检查聊天中的岗位与数量、数据库终态、原任务是否继续、未知结果是否保留，以及忙碌发送、文字/按钮停止、清理超时、失败、跨会话、重复请求和刷新恢复。组件检查与受控链路验证不等于真实招聘网站成功率或任意自然语言准确率。
