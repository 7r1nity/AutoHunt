# 统一启动验证（2026-11-21）

## 交付行为

- 根目录 `start-local.cmd` 默认启动完整模拟站（8080）、Agent（8000）和工作台（3000）；根目录 `stop-local.cmd` 停止整个受管实例。
- `mock-site/start-local.cmd` 单独启动模拟站；本目录的停止入口同样停止整个受管实例。`-Services autohunt` 保留仅启动 AutoHunt 的方式。
- 模拟站先就绪；停止时 Agent 先退出，随后模拟站释放数据库连接，再清理前端。端口冲突不会接管或终止外部服务。
- 完整模拟站只提交源码及虚构种子生成逻辑，已有个人数据库、账号历史、简历、配置、日志及浏览器资料不随仓库分发。
