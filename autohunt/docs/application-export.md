# 申请列表导出与 Harness 结果交付

2026-11-26 更新。

申请看板提供“下载 Excel”“下载 CSV”。默认范围为“全部历史（含已移除）”；可切换“当前看板”。下载只读取本地记录，不调用模型，不启动搜索、发送消息、投递、核验或更改任务状态。

## 导出内容与范围

- 全部历史：读取完整岗位记录，包括隐藏和已移除岗位，无 100 条截断。
- 当前看板：只读取当前可见且未移除的岗位，也不截断为 100 条。
- 每个岗位一行，包含岗位、公司、地点、薪资原文、匹配分、看板状态、沟通状态、队列状态、最近一次投递执行及回执、执行记录数、来源链接和时间。
- “全部历史”表示完整岗位范围；多次投递尝试不重复展开成多行。最近一次尝试以开始时间和记录序号确定，执行记录数保留尝试数量。
- “执行已完成”“已入队”和“已核实投递”分开表示。没有成功回执不会补写为已投递；结果未知仍明确标注待核验。

CSV 使用 UTF-8 BOM，便于 Excel 读取中文。Excel 使用真实 `.xlsx` 工作簿，支持冻结表头、列宽及超过单工作表行数时分表；不是改后缀的 CSV。空记录输出表头，缺失字段留空，实际为零的分数保留为零。

## Harness 中的位置

模型负责理解和规划，执行器负责动作及回执，导出模块负责将持久化证据交付给用户。其接口是确定性的 `export_applications(job_store, format, scope)`，两种文件格式共用同一个字段投影与只读查询。

```text
岗位与投递持久化记录
       ↓ 只读快照
Harness 导出模块
       ↓ 固定字段、状态翻译、文件编码
认证后端 → 同源代理 → 用户下载 Excel / CSV
```

入口为 `GET /api/v1/applications/export?format=csv|xlsx&scope=all|board`，默认 `format=xlsx&scope=all`。前端仅访问 `/api/agent/applications/export`，后端密钥留在服务端，下载禁用缓存。

只导出明确列出的业务字段，不序列化整行数据库、简历正文、联系方式、聊天正文、授权令牌或内部执行参数。链接仅保留可用的 HTTP/HTTPS 来源，去除凭据参数。CSV 对公式前缀作文本保护；XLSX 将外部文本显式保存为字符串，不生成公式或自动超链接。

## 成长计划移除

成长计划的页面、快捷入口、模型工具、HTTP 代理与接口、规划执行分支和专属存取方法已删除。新任务不能再创建该动作；旧活动记录中的未完成步骤会退休并记录原因，不重放副作用。已完成历史不删除，旧会话状态可读取，恢复时不再激活旧的成长待办。

简历上传、人工确认的简历修改提案、候选人画像、分层上下文、搜索、投递、面试准备与 trace 继续保留。历史技术文档、冻结语料与评测报告中的成长计划描述对应旧版本，不能用来证明当前能力。
