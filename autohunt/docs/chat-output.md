# 对话输出与工具记录分离

对话默认使用自然语言。任务编排、浏览器控制、待确认动作与 Mock Provider 共用结果格式化层；未知工具不会兜底输出字典。搜索启动、投递入队、简历提案、人工接管与实际完成分别描述，不把工具成功当作整个任务完成。

主 Agent 在保存回复和会话上下文前检查内部 JSON / Python 字典；LLM 照搬工具数据时，优先使用本轮实际工具 Observation 生成说明，而不是再请求模型改写或重试工具。补充提示词是辅助约束，不是唯一保障。普通 Markdown、代码示例和可点击职位链接不变。

历史会话读取只转换展示，原始数据库记录不改写、不删除。前端对话及“查看回复”有额外的缓存/旧服务显示兜底。完整结构化工具结果仍保留在运行事件和检查点，API 的数据协议依然使用 JSON。

核验使用合成工具结果、替身执行器和独立临时数据库，覆盖规则分支、LLM 分支、任务编排、历史显示、异常和未知结果，不执行真实搜索、投递或历史清理。依既有仓库要求未恢复常驻自动化测试套件；暂无持续自动回归覆盖。
