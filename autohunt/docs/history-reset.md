# 临时历史清理入口

页面右上角「清除历史数据」打开确认弹窗，不会立即删除数据。确认后调用经过 API Key 校验的本地维护接口，成功后刷新页面，并删除旧的 `autohunt-conversation` 浏览器缓存。

- AutoHunt：清空所有会话、运行/搜索记录、简历、材料、画像与偏好、申请看板、投递队列/授权、成长计划、路由历史及业务审计文件。监测、自动提交与每日任务关闭，避免重新同步旧记录。
- 可选模拟站：清空简历、沟通消息、投递和表单作答；保留账号、职位库、表单模板。仅支持管理员显式配置的本地 SQLite 文件，不接受前端传入路径，不支持真实招聘平台。
- 保留模型设置、密钥、浏览器登录、当前规则及技能。原数据先备份到 `AUTOHUNT_DATA_ROOT/history-backups/<backup_id>`；备份包含个人数据，不应提交到 Git。清空当前数据不等于物理擦除备份。
- 运行、接管、待确认、上传、同步或投递未结束时拒绝清理；清理期间阻止其他 API 操作。清理不是 Agent 工具，不会从聊天、JD 或模型输出触发。
- 请求/连接失败时不自动重试；结果不明确需刷新核对。多数据库/文件清理有备份和异常回滚，但不是跨进程、跨数据库的崩溃原子事务。

配置：默认关闭，当前本机调试可设 `AUTOHUNT_HISTORY_RESET_ENABLED=true`；不需要时改为 `false` 并重启后端。需要同时清模拟站时，设置 `AUTOHUNT_MOCK_HISTORY_DATABASE` 为本地模拟数据库的绝对路径。该临时功能仅用于当前单进程本地服务，不用于多 worker / 多用户部署。

核验使用临时数据库及合成文件，不清除用户当前简历或历史。依用户要求未恢复常驻自动化测试套件，暂无自动回归覆盖。
