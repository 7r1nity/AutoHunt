# 场景测试集

按项目负责人要求重建（此前自动化测试源码、夹具与入口曾被移除）。**不依赖 pytest**，只用标准库，
因此不需要新增依赖即可运行。

## 运行

```powershell
cd agent
.\.venv\Scripts\python.exe tests\run_scenarios.py                       # 只跑离线层（默认）
.\.venv\Scripts\python.exe tests\run_scenarios.py --layer offline --layer state
.\.venv\Scripts\python.exe tests\run_scenarios.py --layer site          # 需模拟站在 8080
.\.venv\Scripts\python.exe tests\run_scenarios.py --layer model         # 会真实调用 LLM
.\.venv\Scripts\python.exe tests\run_scenarios.py --list                 # 只列用例
.\.venv\Scripts\python.exe tests\run_scenarios.py --group 多轮 --verbose
.\.venv\Scripts\python.exe tests\run_scenarios.py --id cx
```

退出码：全部通过为 `0`，存在真实失败为 `1`。

## 分层（为什么必须显式选择）

| 层 | 含义 | 代价 |
|---|---|---|
`offline` | 不碰网络、模型、数据库；纯函数与规则引擎 | 免费，默认运行 |
`state` | 使用 `tempfile` 建临时 SQLite，验证存储与状态迁移 | 免费，需显式请求 |
`site` | 需要本地模拟站（127.0.0.1:8080） | 需先启动模拟站 |
`model` | 真实调用已配置的 LLM | 花钱、耗时、结果带随机性 |

测试全部落在临时数据根（`tests/.tmp-data-root`），**不会触碰你的看板数据**。

## 当前结果

```
offline + state + site   通过 150   失败 0   已知缺陷 2
```

### 已知缺陷（xfail，用例保留但标记为预期失败）

| 用例 | 缺陷 |
|---|---|
`jd21` | `candidate_skills=[]` 时评分器仍返回 65 分（decision=REVIEW），且命中/缺失技能都是空。**没有可比对技能时不应给出可用的匹配分**，应明确表达"信息不足"。 |
`dc02` | `automation_decisions` 表有写入方，但 `store.py` 之外没有任何读取方——决策账本只写不读，承诺的可观测性没有兑现。 |

修好后请**移除对应的 `xfail` 标记**；若某个 xfail 用例开始通过，运行器会提示标记已过期。

### 这一类用例的价值：套件曾抓出两个真实缺陷

1. **`城市规划师` 这类职称会被解析器丢弃**（`core/search_language.py` 的 `_FIELD`）。
   字段边界正则把城市名"城市"当作分隔点，`10份城市规划师` 被切成 `["10份", "城市规划师"]`，
   数量子句里没有岗位词，于是**岗位词整条丢失、请求被判为不完整**。凡是以字段标签开头的职称
   （城市经理、数据分析师…）都受影响。已修复。
2. **关键词归一化只剥一层前缀**。`高级 LLM 算法工程师` 只被剥成 `LLM 算法工程师`，
   `AI/LLM 算法工程师` 完全没被剥（斜杠形式不匹配）。已修复。

这两条都属于"跨行业提取"类，是纯离线用例就能发现的——正是这个套件存在的理由。

## 约定

- **只断言可观察行为**：解析结果、路由决策、状态迁移、落库行。不依赖内部调用顺序，便于重构。
- **夹具必须填满 NOT NULL 列**：`jobs` 表的 `source`/`location`/`salary`/`description`/`tags`
  都是必填，缺列会以 `IntegrityError` 暴露，这是刻意的。
- **临时库需要收敛连接**：`JobStore` 从不关闭 SQLite 连接（已知缺陷 D10），Windows 上文件会被锁住。
  测试用 `ignore_cleanup_errors=True` 与显式关闭来隔离，**这是为产品缺陷做的规避，不是测试的便利**。
- **`site` 层只针对本地模拟站**。真实招聘网站禁止爬取，本套件不含任何真实站点写操作，
  也不绕过验证码/MFA。
