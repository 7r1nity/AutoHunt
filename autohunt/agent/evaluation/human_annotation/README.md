# 人工标注工作台

独立本地网页，标注已冻结的 `jev-ranking-v1.json` 三档岗位匹配数据集。无需启动 Agent 或模拟招聘站，不读取 `.env`、个人简历、聊天和投递队列，不调用任何模型。

## 启动

在 `autohunt/agent` 目录执行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn evaluation.human_annotation.web:app --host 127.0.0.1 --port 8011
```

打开 [本机标注页](http://127.0.0.1:8011/)。仅绑定本机，不能直接作为多人联网标注平台部署。

默认数据库位于 `evaluation/results/human-annotations/<语料指纹前12位>/annotations.sqlite.db`，被 Git 忽略。标签保存在 SQLite，浏览器只保存标注员、范围、轮次与最近样本位置。备份应在服务停止后复制此数据库；没有删除/重置按钮，不会误删进度。可通过环境变量 `AUTOHUNT_ANNOTATION_DB` 指定另一份本地数据库；数据集指纹不一致时拒绝复用。

## 标注方式

1. 填写标注员名称或代号，先选择「校准集 · 64 对」，阅读「标注指南」。校准集与原先生成的 `human-calibration.jsonl` 采用同一选样规则，全部来自开发集。
2. 并排阅读候选人材料和 JD。点击正文段落选取证据，再次点击取消；服务端由行号提取原文，不接受前端自行编造引用。
3. 分别填写匹配等级（0 明显不匹配 / 1 部分匹配 / 2 高度匹配）和硬条件（满足 / 不满足 / 信息不足），必要时写理由。缺信息不等于不会；技能关键词重合不能抵消年限、职责深度等要求。
4. 修改后约 900ms 自动保存草稿；「完成并下一条」计入完成数。缺标签不能完成；缺一侧证据或高匹配却硬条件不满足的记录允许保存，同时标记需复核。用户可修正、补证据后解除复核。
5. A、B 由不同人员独立标注。默认隐藏另一轮答案，切换到已有他人记录的轮次不会直接展示其答案。明确点击「查看他人标注 / 仲裁对照」才显示，且持久记录查看事实。当前未接入 Jev 标签展示，不会把作者设计分当模型标注。
6. 第三人仲裁须先完成 A、B，两位已有标注员不可用同一名称自仲裁。仲裁必须给理由，并绑定 A、B 版本；后续 A/B 改动使旧仲裁失效，需重新仲裁。

支持校准集64对、开发集160对、保留测试集140对、全量300对；按状态、JD/岗位名/ID搜索；键盘 `1/2/3` 选择 0/1/2级，`Q/W/E` 选择硬条件，`Ctrl+Enter` 完成。笔记输入框不触发标签快捷键。相同样本在多个范围下共享同一标注，切换范围不会复制样本或清空标签。

相同标注槽的并发保存采用 `expected_revision` 乐观锁。冲突返回409并保留当前页面修改，不静默覆盖另一页面；复制未保存的笔记，刷新读取新版本后处理。

## 导出与参考标签

右上角导出 **JSON** 或 **CSV**，包含全部范围所有已保存记录，不仅是当前筛选范围。导出先保存当前未提交的草稿。

- JSON：数据集版本及 SHA256、标注员自报名称、每轮标签和原文证据、草稿/跳过/需复核状态、修订版本、查看他人答案的记录、完整修改事件。
- CSV：逐轮可读记录，UTF-8 BOM，兼容 Excel；对可能触发公式的文本加前置单引号。CSV不含完整审计历史，归档优先使用JSON。
- `reference_labels`：仅包含两份独立、未受参考答案影响且有双方证据的一致完整标注，或有证据且依据未过期的第三人仲裁。单人标注、草稿、待核实样本不会自动升级为此类参考。
- 标注员身份由本机用户自行填写，系统没有身份认证；上述独立性只基于声明和操作记录，不能声称已验证两位真人身份。

保留测试集须在统一口径后独立标注，不能边看模型结果边调标签。统计 Precision@5、Recall@5、NDCG@5 时需完整评审同一候选人的20个岗位，并明确开发/测试、标签来源与覆盖率。64对校准子集不足以证明完整排序质量。

本工具导出的人工参考与原 Jev 原始响应不是同一来源。现有 `jev_labels.evaluate score` 专门验证 Jev 响应及其 provenance，不能将人工JSON冒充Jev标签直接传入；后续评分应显式新增人工参考适配并注明来源。本工具不自动恢复暂停的 Jev 任务，不消耗其预算。

## 测试

在 `autohunt/agent` 运行：

```powershell
.\.venv\Scripts\python.exe -m evaluation.human_annotation.contracts
.\.venv\Scripts\python.exe -m evaluation.human_annotation.browser_checks
```

第一项为16项离线接口/存储契约，覆盖盲审隔离、证据、持久化、版本冲突、仲裁过期、导出与本机请求保护。第二项启动隔离数据库和临时端口，使用本机 Chrome 无头浏览器验证9组网页流程与窄屏布局；结束后停止该测试服务，不操作正式标注数据库。截图和原始汇总保存在被忽略的 `evaluation/results/human-annotation-browser/`。

这两类测试证明工具的工程行为，不代表人工标签已产生，也不是匹配模型质量评估。没有新增真实模型调用或招聘动作。
