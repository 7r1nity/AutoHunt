让每个分数都有依据

这批 300 对材料均为虚构数据。每条由一份候选人材料和一条 JD 组成，不预设正确答案。

  1. 先读材料与 JD，区分「必需」和「优先」。岗位标签相同不代表经验深度相同。
  2. 分别选择匹配等级和硬条件结论。缺失信息选「信息不足」，不要猜测。
  3. 点击两侧原文选取证据，填写判断理由，再「完成并下一条」。
  4. A、B 由不同人员独立填写；有分歧时由第三人仲裁。标注员名称为自行填写，系统不验证身份。

先做 64 对开发校准集并统一口径，再独立标注保留测试集。不要用测试集调参。
