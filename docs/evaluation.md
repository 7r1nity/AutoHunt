# AutoHunt 隔离评估

2026-10-10 用户明确要求生成更大规模测试集、保存结果和日志并定位失败，因此恢复持久评估源码。本次是评估交付，不宣称已修复评估发现的业务缺陷。

## 运行

在 `agent` 目录运行：

```powershell
.\.venv\Scripts\python.exe -m evaluation.run
.\.venv\Scripts\python.exe -m evaluation.run --browser-fixtures --kinds browser
```

前者使用临时 SQLite、生产解析/校验/DST/执行代码与合成执行器；不读取个人数据库、不启动服务、不使用当前浏览器。后者启动新的无头 Chromium，所有请求在浏览器中拦截/中止，只验证生产 DOM 适配器。没有启动模拟站的后端，也没有向真实网站发送请求。

获得向已配置 DeepSeek 发送合成请求/JD 的明确同意后才运行：

```powershell
.\.venv\Scripts\python.exe -m evaluation.run --models-consented --models-only --model-call-limit 120
```

模型模式只读模型配置/加密凭据，不读取简历、聊天或申请记录，不调用招聘工具。120 是本进程物理 API 请求上限，规划修正也计入，无传输自动重试。多次运行需要人工累计预算；本次经用户同意总计不超过120次。可用 `--kinds model_expression model_dialogue` 选择层，`--repetitions 2` 重复同一批表达；重复尝试不是新独立样本。

失败返回非零退出码，保留所有失败，不用 xfail/放宽期望掩盖。无同意的模型层、未选择的浏览器层显示 skipped，不算通过。静态验证入口 `scripts/verify.ps1` 与行为评估分开。

## 数据集与日志

`agent/evaluation/corpus.py` 定义合成数据及独立期望，`run.py` 定义被测入口/断言。当前共 2,161 个案例规格，24 个行业；数量包含组合变体，不等于2,161个人工审核的独立语义样本。

主要覆盖：

- 搜索命令与询问/引用/撤销；对象条件否定、条件句、引号及复合任务。
- 数量、月薪单位、城市、上下游分支分数/薪资隔离，冲突与非法参数。
- 槽位继承、主简历刷新与显式会话岗位保留、真实追问补参、持久任务续接、话题/修复信号、序号快照。
- 一次性确认、过期和版本变化、工具重复/循环预算、低置信度向主模型降级。
- 模拟投递预览、一次性令牌消耗/防复用、预览篡改/过期、岗位事实变化、未知筛选不授权、主简历内容/版本绑定及真实站投递禁用；只在临时数据库验证，不实际发送。
- all/any/not 三值逻辑、原文证据核验、无效索引/字段/JSON、模拟模型不可验证、取消传播。
- 超时/权限/服务故障分类、只读重试、外部动作不重试、watchdog、取消后 join。
- SQLite 请求去重、会话隔离、重启保留、终态不可变；DAG 等待、失败/撤销/简历变化、独立分支及不确定写入不重放。
- 登录/MFA/验证码、HR 回复/锁定、无简历、已发送、沟通遮罩、关页及岗位卡片的隔离 Chromium DOM 观察。
- 真实 DeepSeek：48个跨行业搜索/多目标规划、24个JD判断、12种表达、16个多轮规划场景；另重复12种表达测稳定性。

每次生成 `agent/test-results/evaluation/<UTC时间>/`：

| 文件 | 内容 |
|---|---|
| `dataset.json` | 本次完整案例规格和期望，便于复跑 |
| `cases.jsonl` | 案例/尝试编号、输入、期望、实际、耗时、错误及生产事件轨迹；逐条刷盘 |
| `model-calls.jsonl` | 合成提示、原始响应、请求次数、token usage与耗时，不含密钥/请求认证头 |
| `summary.json` | 版本/数据集指纹、分层指标、源码指纹及运行中源码变化（新版runner）、模型用量 |
| `failures.json` | 所有失败/错误；不覆盖首轮失败记录 |
| `report.md` | 可读结果和能力边界 |

目录被 Git 忽略，日志保留本地；仓库只提交生成器、执行入口、合成夹具和脱敏评估摘要。数据集的 challenge 按表达家族划分，不随机拆分近重复语句；本次已阅读失败并进行诊断，因此不能再称为未看过的盲测集。以后调优必须另留未使用的新家族。

## 首轮结果与原因

详见 [2026-10-10 评估报告](evaluation-2026-10-10.md)。没有用一个“意图准确率”混合不同层：整体模板规划通过，不代表换表达、授权或执行闭环通过；匹配评分也不能替代硬条件证据。

未覆盖：完整模拟站后端→Agent→HR回复→授权简历→投递回执的闭环、真实平台登录/DOM兼容、前端完整交互、配置小模型的真实分类质量、简历解析与成长计划内容科学性。不得由上述通过数推出这些能力已验收。
