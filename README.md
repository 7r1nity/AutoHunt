# AutoHunt

面向求职流程的本地 AI Agent，将简历材料、自然语言需求、职位筛选、申请跟踪与成长建议组织成可追踪的任务链路。

项目采用 **Plan-and-Execute + 持久化任务状态**：模型负责语义理解与规划，执行器按依赖推进步骤、记录结果，并对有副作用的操作进行授权和结果核验。当前定位为单用户研究与演示项目，不是已完成真实招聘网站验收的自动投递产品。

## 功能

- **候选人材料**：导入简历、提取项目证据、生成待审核的修改提案；用户确认后才写入主简历。
- **组合需求**：城市、薪资、实习/正式岗位、分组数量及 JD 语义条件；支持全部、任一和否定条件。
- **筛选和匹配**：保存职位原文与依据，区分满足、不满足和信息不足；匹配分不能覆盖硬条件。
- **动态任务**：追加步骤、修改未执行参数、暂停、停止与接续；区分已完成、失败和结果未知。
- **申请进度**：看板、稳定序号选岗、单独/批量投递范围、后台 HR 回复监测与状态同步。
- **成长建议**：根据选定 JD 和当前简历分析证据差距、生成学习计划；完成学习不等于系统认证能力。
- **执行证据**：关联运行、计划版本、步骤、模型调用与工具回执，记录可用的延迟、Token 和重试信息。

## 核心设计

```text
用户请求 + 会话状态 + 可追溯历史
                 ↓
        意图路由 / 模型语义规划
                 ↓
        持久化计划、依赖与版本
                 ↓
       工具网关 → 执行器 → 结果核验
                 ↓
       看板、总结、任务状态与后续步骤
```

| 层面 | 实现与取舍 |
| --- | --- |
| 前端 | Next.js、React、TypeScript；同源服务端代理，不向浏览器暴露后端服务密钥 |
| 后端 | Python 3.12+、FastAPI；单 Agent 编排，不提供多 Worker 分布式执行 |
| 模型与工具 | 确定性快路径、可选小模型、主模型工具调用；本地 stdio MCP 接口 |
| 任务执行 | 持久化计划与步骤回执、动态修订、依赖调度、取消传播、受限失败恢复 |
| 数据与记忆 | SQLite、加密私有材料；结构化条件独立于历史摘要，召回保留原文来源 |
| 浏览器 | Playwright、专用浏览器会话、页面证据检查；登录、验证码和 MFA 人工接管 |
| 副作用保护 | 预览、一次性授权、简历绑定、重复保护；未知投递只读核验，不盲目重发 |

## 快速开始

应用源码位于 [autohunt/](autohunt/)。安装依赖、初始化配置及启动前后端，见 [安装与运行指南](autohunt/README.md)。

Windows 用户安装 Python 3.12+ 和 Node.js 20.9+ 后，可双击根目录 `start-local.cmd` 一键准备并启动工作台，双击 `stop-local.cmd` 停止服务。详情及日志位置见安装与运行指南。

默认前端地址为 [http://127.0.0.1:3000](http://127.0.0.1:3000)，后端监听 `127.0.0.1:8000`。首次配置默认使用 Mock 模型；真实语义规划需要在设置中配置支持的模型服务。

**模拟招聘网站已从当前 Git 跟踪中移除，不随仓库分发。** 本地已有的 `mock-site/` 可继续独立使用，其文件、账号和数据不会因取消跟踪而删除。AutoHunt 保留模拟站适配器，但新克隆不能直接运行完整模拟投递演示。BOSS 直聘和智联招聘适配器仅用于只读搜索，真实站沟通、上传简历和提交申请仍禁用。

## 测试与可复现性

当前版本新增冻结任务与源码内置模拟站，见 [当前版本验收与干净安装](autohunt/docs/current-acceptance.md)。一条命令可运行零外部模型的工程/浏览器验收；`--ui` 增加完整每日任务链，真实模型模式需单独获准预算。测试站点位于评测夹具目录，不依赖未分发的业务模拟站。

[2026-11-16 验收结果](autohunt/docs/current-acceptance-2026-11-16.md)：新任务真实模型33/36通过，首次请求暂停场景仍有失败；干净环境的工程/浏览器/UI检查通过。没有用工程通过数替代模型语义成绩。

评估源码位于 [autohunt/agent/evaluation/](autohunt/agent/evaluation/)，区分三个层次：

1. **离线工程契约**：用合成输入、脚本模型和临时数据库检查规划、执行、筛选、授权、恢复与状态一致性。
2. **合成模型评估**：检查不同表达和多轮请求下的模型输出；需单独同意数据发送范围与调用预算。
3. **浏览器与端到端验证**：隔离页面检查不能代替完整网站闭环；部分浏览器用例依赖未随仓库发布的本地模拟站页面。

运行命令及覆盖边界见 [评估说明](autohunt/docs/evaluation.md) 和 [恢复、对账与记忆验证](autohunt/docs/recovery-reconciliation-memory.md)。通过数不等于自然语言准确率、真实网站成功率或生产可靠性承诺。运行日志和个人数据不提交 Git。

最新实测见 [2026-10-26 分层评测报告](autohunt/docs/benchmark-2026-10-26.md)：30 份虚构简历、100 条 JD、450 对参考标签，20 组真实模型多轮规划，以及 96 次隔离浏览器/模拟站对照试验。包含失败与框架修正记录；标签尚待人工复核，正向投递完成率与安全停止率分别报告。
